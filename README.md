# AlphaBet product shell

An original, mobile-first casino product shell in a pnpm/Turborepo workspace.

## Run locally

```bash
pnpm install
pnpm dev
```

- Web: http://localhost:3000 (redirects to `/en/casino`)
- BFF health: http://localhost:4000/health

Quality checks: `pnpm build`, `pnpm typecheck`, `pnpm lint`, and `pnpm test`.

Copy each `.env.example` to `.env.local` only if overriding the local defaults. The BFF is
intentionally limited to health/status endpoints. Casino data is generated by the web app's
mock repository behind `getLobby()` and `search()` contracts.
