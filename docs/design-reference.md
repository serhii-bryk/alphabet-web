# Design reference boundaries

This shell uses familiar product patterns without reproducing another product's identity.

- Stake informs only information architecture, navigation hierarchy, and content density.
- Shuffle informs only immediate game-card interaction patterns.
- MyStake informs only motion ideas for category and compact promotion rails.

No branding, assets, color system, copy, or pixel-level layout is copied. The visual identity,
token system, geometric game artwork, motion, and “AlphaBet” wordmark are original to this project.
External image assets are not used.
